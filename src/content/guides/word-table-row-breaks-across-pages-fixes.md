Word 문서에서 표의 한 행이 두 페이지로 갈라지거나, 표가 다음 장으로 밀리고 앞 페이지 아래가 크게 비어 있나요? 같은 문제처럼 보이지만 원인은 다를 수 있습니다. **행을 나누지 않게 하는 설정**, **고정된 행 높이**, **단락의 페이지 나누기 설정**을 구분해야 불필요한 서식 손상을 피할 수 있습니다.

이 글은 Microsoft 365·Word 2024·Word 2021의 데스크톱 앱을 중심으로 정리했습니다. 메뉴는 Windows와 Mac, 프로그램 버전에 따라 달라질 수 있습니다. 모든 환경에서 실제 테스트했다는 의미는 아닙니다.

## 증상별 점검 순서

| 증상 | 먼저 확인할 설정 | 해결 방향 |
| --- | --- | --- |
| 한 행이 페이지 경계에서 갈라짐 | 표 속성 → 행 | 페이지에서 행 나누기 허용 |
| 표가 통째로 다음 장으로 밀림 | 행 분할 여부·단락 묶음 | 필요한 문단만 함께 유지 |
| 표 아래 글자가 잘려 보임 | 행 높이 '정확히' | 높이 조건·셀 여백 조정 |
| 긴 표의 두 번째 페이지에 제목이 없음 | 머리글 행 반복 | 표 첫 행부터 반복 지정 |
| 페이지 아래에 큰 공백이 생김 | 수동 페이지 나누기·단락 옵션 | 빈 단락과 나누기 구별 |
| 인쇄 또는 PDF에서 위치가 달라짐 | 인쇄 모양·용지 설정 | 미리보기 후 검증 |

### 0. 원본을 보관하고 편집 기호부터 보기

먼저 **파일 → 다른 이름으로 저장**으로 작업용 복사본을 만드세요. 회사의 서식이나 논문처럼 표가 많은 문서에서는 구역 나누기·머리글·용지 방향을 잘못 변경하면 복구가 어려울 수 있습니다.

**홈 → ¶ 표시/숨기기**를 켜 수동 페이지 나누기, 구역 나누기, 빈 단락을 살펴봅니다. **보기 → 인쇄 모양**으로 전환해 표의 시작 행·페이지 경계·마지막 행을 확인하세요. 복사본에서 한 설정씩 변경하고 결과가 좋아지는지 살펴보는 것이 좋습니다.

## 1. 표의 한 행이 다음 페이지로 갈라지지 않게 하기

1. 문제가 발생한 표에서 해당 행을 클릭하거나, 분할을 금지할 행을 선택합니다.
2. 마우스 오른쪽 단추를 누르고 **표 속성**을 엽니다.
3. **행** 탭으로 이동합니다.
4. **페이지에서 행 나누기 허용**에 해당하는 체크 표시가 있다면 해제합니다.
5. **확인** 후 인쇄 모양으로 결과를 확인합니다.

이 설정은 해당 행이 페이지 경계에서 둘로 나뉘지 않도록 하는 용도입니다. 남은 공간이 부족하면 행 전체가 다음 페이지로 이동할 수 있습니다. 따라서 설정 후 앞 페이지 아래가 비는 것은 반드시 오류가 아닙니다.

**예외:** 한 행이 인쇄 가능한 페이지 높이보다 크다면 행 전체를 한 페이지에 담을 수 없습니다. 행을 여러 개로 분리하거나 이미지·문단 길이를 조절하고, 분할을 허용할 필요가 있는지 판단해야 합니다. 모든 행의 분할을 일괄적으로 금지하는 것은 권장하지 않습니다.

## 2. 표 행이 통째로 밀리고 큰 빈 공간이 생길 때

앞 페이지에 남은 높이보다 행이 크거나 여러 문단이 묶여 있으면 Word가 내용을 다음 페이지로 배치할 수 있습니다. 먼저 다음 항목을 순서대로 확인합니다.

- 표 행에 **페이지에서 행 나누기 허용**이 꺼져 있는지 확인합니다. 긴 설명 행에는 분할 허용이 적절할 수도 있습니다.
- 표가 시작되는 곳에 불필요한 **수동 페이지 나누기**가 있는지 살펴봅니다.
- 표 위 제목과 표 안 문단의 **다음 단락과 함께** 옵션이 여러 문단에 연속으로 적용됐는지 확인합니다.
- 셀 안 그림·문단·중첩 표가 행 높이를 과도하게 키우지 않았는지 살펴봅니다.

수동 페이지 나누기와 자동 페이지 나누기는 다릅니다. Microsoft에 따르면 자동 페이지 나누기는 직접 삭제할 수 없고 단락 배치 옵션으로 조절합니다. 의도적으로 넣은 구역 나누기는 표 위치를 바꾸려고 무턱대고 지우지 마세요.

## 3. 셀 속 글자가 아래쪽에서 잘려 보일 때

페이지 경계 문제가 아니라 **고정된 행 높이**가 텍스트를 가리고 있을 수 있습니다.

1. 문제가 있는 행을 선택합니다.
2. **표 속성 → 행**에서 **높이 지정** 여부를 확인합니다.
3. 행 높이가 **정확히(Exactly)**로 고정돼 있다면 그 값이 셀 안의 내용과 여백에 충분한지 확인합니다.
4. 필요할 때 높이 제한을 해제하거나 **최소값(At least)** 조건으로 변경합니다.
5. 셀 안의 문장·사진·표가 모두 보이는지 다시 확인합니다.

'정확히'는 행 높이를 고정하기 때문에 추가된 줄이 가려질 수 있습니다. '최소값'은 내용이 더 많은 공간을 필요로 하면 행이 커질 수 있습니다. 셀 여백과 단락 간격도 행 높이에 영향을 줍니다. **본문 글꼴을 무작정 줄이거나 내용을 삭제하기 전에** 고정 높이를 확인하세요.

## 4. 단락의 '다음 단락과 함께' 점검하기

Word의 단락 페이지 설정은 표 안의 텍스트 배치에도 영향을 줍니다. 내용이 다음 페이지로 많이 밀리면 다음을 확인하세요.

1. 표 안에서 영향을 받는 문단을 선택합니다.
2. **홈 → 단락 대화 상자 실행 단추**를 누릅니다.
3. **줄 및 페이지 나누기** 탭을 엽니다.
4. **다음 단락과 함께**, **줄을 함께 유지**, **단락 앞에서 페이지 나누기** 항목을 확인합니다.
5. 필요한 목적 없이 과도하게 적용된 옵션만 해제하고 다시 확인합니다.

**다음 단락과 함께**는 제목과 뒤의 설명을 같은 페이지에 두기 위한 기능입니다. **줄을 함께 유지**는 한 문단의 여러 줄을 한 페이지에 놓는 기능이고, **단락 앞에서 페이지 나누기**는 해당 문단 앞에서 새 페이지를 시작하는 설정입니다. 서로 다르므로 무작정 모든 체크를 끄지 마세요.

긴 표의 여러 문단이 계속 묶여 있다면 표가 뒤로 밀릴 수 있지만, 표 위의 제목 한 줄 정도는 표와 함께 유지하는 것이 오히려 읽기 좋을 수 있습니다.

## 5. 다음 페이지에 표 제목 행을 자동 반복하기

견적서나 보고서의 표가 여러 페이지에 걸쳐 있다면 각 페이지 맨 위에 항목 이름을 반복하는 것이 편리합니다. Microsoft는 **반복 대상으로 표의 첫 번째 행이 포함돼야 한다**고 안내합니다.

1. 표의 **첫 번째 행**을 선택합니다. 두 줄짜리 제목이라면 첫 행을 포함해 머리글 행들을 함께 선택합니다.
2. **표 레이아웃 → 데이터 → 머리글 행 반복**을 선택합니다.
3. 또는 **표 속성 → 행 → 각 페이지 맨 위에 머리글 행으로 반복**을 선택합니다.
4. **인쇄 모양**에서 두 번째 페이지의 제목 행을 확인합니다.

반복된 제목 행은 원본 첫 행을 기준으로 표시됩니다. 수정하려면 표의 첫 페이지에 있는 원래 제목 행을 수정하세요.

**중요:** Microsoft는 표가 **자동 페이지 나누기**로 다음 장에 이어질 때 제목 행 반복이 동작하며, **표 안에 수동 페이지 나누기를 삽입한 경우 반복되지 않는다**고 설명합니다. 반복 옵션만 다시 누르기 전에 수동 나누기가 있는지 확인하는 이유입니다.

## 6. 머리글 행 반복이 작동하지 않을 때

첫째, 제목으로 설정한 행에 표의 첫 행이 들어 있는지 확인합니다. 두 번째 행만 선택해서는 원하는 결과가 나오지 않을 수 있습니다.

둘째, 겉보기엔 하나의 표지만 사실 두 개의 별도 표인지 살펴봅니다. 사이에 빈 문단이 있으면 문서 구조를 먼저 확인해야 합니다.

셋째, 표 안의 수동 페이지 나누기를 확인합니다. 의도적으로 삽입한 것인지 확인한 후, 불필요하다면 복사본에서 제거를 검토합니다.

넷째, **인쇄 모양**을 사용합니다. Word의 표 제목 반복은 이 보기 또는 인쇄 시 확인할 수 있습니다.

다섯째, 셀 병합이 많거나 다른 문서에서 붙여넣은 표라면 먼저 표 구조를 살펴봅니다. 병합이나 분할을 함부로 바꾸면 제목과 데이터의 의미가 달라질 수 있습니다.

## 7. 표 안 그림·셀 병합·너비가 원인인지 확인하기

한 셀에 큰 이미지가 있거나 여러 열이 병합돼 있으면 표의 행 높이와 페이지 배치가 복잡해질 수 있습니다.

- 셀 안 사진의 크기와 가로세로 비율을 확인합니다.
- 표가 용지 여백을 벗어나지 않는지 **표 레이아웃**에서 열 너비와 자동 맞춤 옵션을 점검합니다.
- **표 속성**의 텍스트 줄 바꿈 설정이 '주위'로 되어 있으면 다른 본문과의 배치도 확인합니다.
- 병합된 셀과 중첩된 표를 삭제하거나 분할하기 전에 반드시 사본을 만듭니다.
- 다른 프로그램에서 표를 붙여넣었다면 글꼴, 문단 간격, 고정 행 높이 같은 서식도 확인합니다.

행 내용에 큰 그림이 있으면 페이지가 달라지는 것 자체가 자연스러울 수 있습니다. 모든 내용을 억지로 한 장에 맞추면 글자가 너무 작아져 가독성이 떨어집니다. 문서를 읽는 사람에게 필요한 크기를 유지하는 것이 우선입니다.

## 8. 자동 페이지 나누기와 수동 페이지 나누기 구별하기

Word에서 자동 페이지 나누기는 문서 내용이 페이지 끝에 도달할 때 생성됩니다. 수동 페이지 나누기는 사용자가 지정한 위치에서 페이지를 바꾸는 기능입니다.

**홈 → ¶ 표시/숨기기**를 켜면 수동으로 삽입한 나누기를 찾아볼 수 있습니다. 불필요한 수동 페이지 나누기가 원인으로 확인된 경우에만 제거하세요.

문서 중간의 **구역 나누기**는 별개입니다. 이를 삭제하면 여백, 용지 방향, 머리글·바닥글 등이 달라질 수 있으므로 표만 해결하겠다고 삭제하지 마세요. 수동 나누기가 아닌 경우에는 단락 설정이나 행 설정을 조정하는 것이 맞습니다.

## 9. Mac용 Word와 웹용 Word에서의 차이

**Mac용 Word**는 표를 선택하면 표 디자인·레이아웃 관련 기능을 사용할 수 있습니다. Microsoft 공식 안내에는 표 크기, 행·열 크기 조정 방법이 제공됩니다. Windows와 메뉴 위치가 다르면 **표 속성**이나 **서식 → 단락**을 확인하세요. 실제 표시 이름은 설치 버전에 따라 다릅니다.

**웹용 Word**에서는 일부 표 편집 기능을 데스크톱 앱만큼 지원하지 않을 수 있습니다. Microsoft도 셀 병합·분할 안내에서 웹·모바일 앱에 기능 제한이 있음을 설명합니다. 메뉴가 보이지 않으면 데스크톱 앱에서 문서를 열어 편집하고 저장 결과를 확인합니다.

공유 문서는 다른 사람이 동시에 수정하고 있을 수 있습니다. 표 구조를 바꾸기 전 변경 범위와 책임자를 확인하고, 원본·버전 기록을 확보해 두는 것이 안전합니다.

## 10. PDF 저장과 인쇄 전 최종 검증

- [ ] 표의 첫 행과 마지막 행이 모두 존재한다.
- [ ] 페이지 경계에서 텍스트가 가려지지 않는다.
- [ ] 각 행의 분할 여부가 문서 목적과 일치한다.
- [ ] 제목 행 반복이 필요한 페이지에서 정상 표시된다.
- [ ] 원본과 비교했을 때 행·열 개수와 숫자 데이터가 같다.
- [ ] 문서 여백·용지 방향·페이지 번호가 의도치 않게 바뀌지 않았다.
- [ ] **파일 → 인쇄** 미리보기에서 모든 표의 경계를 살펴봤다.
- [ ] PDF 저장 후 표가 넘어가는 페이지와 마지막 페이지를 다시 확인했다.

표 한 행이 다음 페이지로 넘어가는 것보다 **데이터가 누락되거나 잘린 채로 제출되는 것**이 더 큰 문제입니다. 화면에서 괜찮아 보여도 PDF 결과와 인쇄 미리보기에서 검증하세요.

## 자주 묻는 질문

### Q. Word 표를 한 페이지에서 절대 나누지 않게 할 수 있나요?

표의 특정 행은 **표 속성 → 행 → 페이지에서 행 나누기 허용 해제**로 한 페이지에 유지되도록 설정할 수 있습니다. 다만 한 행 자체가 페이지보다 길면 그 내용을 한 페이지에 담을 수 없으므로 표 구조를 조정해야 합니다.

### Q. 표 앞 페이지에 큰 빈 공간이 생기는 것은 고장인가요?

항상 고장은 아닙니다. 행 전체가 들어갈 공간이 부족하고 행 나누기가 금지돼 있다면 다음 페이지로 이동할 수 있습니다. 단락의 '다음 단락과 함께' 설정도 함께 점검하세요.

### Q. 표 두 번째 페이지에서 제목 행이 안 보이면 어떻게 하나요?

첫 행을 포함해 **머리글 행 반복**을 지정하고 인쇄 모양에서 확인합니다. 표 안 수동 페이지 나누기가 있으면 반복이 나타나지 않을 수 있습니다.

### Q. 행 높이를 바꾸면 데이터가 사라지나요?

행 높이 변경 자체는 텍스트 삭제 명령이 아니지만 '정확히' 고정된 높이 때문에 내용이 가려질 수 있습니다. 원본을 보관하고 결과를 확인하세요.

### Q. 표 전체를 한 페이지에 넣는 것이 가장 좋은가요?

항상 그렇지는 않습니다. 긴 표를 무리하게 축소하면 글자와 수치가 읽기 어려워질 수 있습니다. 표가 여러 페이지에 걸쳐야 한다면 제목 행을 반복하고 페이지 경계를 자연스럽게 만드는 것이 더 낫습니다.
