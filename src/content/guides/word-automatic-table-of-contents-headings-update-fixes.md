Word에서 보고서나 논문의 목차를 직접 입력하면 문단을 추가할 때마다 페이지 번호를 손으로 고쳐야 합니다. 제목이 바뀌거나 장의 순서가 달라지면 목차가 금세 틀어지고, 일부 제목이 사라지기도 합니다. **Word 자동 목차의 핵심은 글자 크기나 굵기가 아니라 ‘제목 스타일’**입니다. 올바른 제목 수준을 지정한 뒤 자동 목차를 삽입하면 문서를 수정한 후에도 목차를 갱신할 수 있습니다.

이 글은 Microsoft Word의 데스크톱 버전(Windows·Mac)을 중심으로, 웹용 Word에서 확인할 수 있는 기능도 구분합니다. Microsoft 365, Word 2024·2021 등 버전에 따라 메뉴 이름이나 배치가 조금 다를 수 있습니다. 특히 다른 사람이 만든 학위논문·기관 양식은 기존 스타일과 필드가 이미 들어 있을 수 있으므로 원본을 보관한 다음 수정하세요.

## 시작 전: '자동 목차'와 '수동 목차' 차이

| 구분 | 자동 목차 | 수동 목차 |
| --- | --- | --- |
| 항목의 원본 | 문서 본문에 적용된 제목 스타일 | 사용자가 직접 적은 글자 |
| 제목 변경 반영 | 전체 목차 업데이트로 반영 | 직접 수정해야 함 |
| 페이지 번호 변경 | 업데이트로 반영 가능 | 직접 수정해야 함 |
| 추천 상황 | 보고서, 논문, 긴 매뉴얼 | 간단한 한 장짜리 안내문처럼 고정된 목차 |
| 흔한 오류 | 제목 스타일 누락·잘못된 수준 | 번호와 항목을 손으로 고치다 생기는 불일치 |

Microsoft는 자동 목차가 문서의 제목을 기반으로 생성된다고 설명합니다. **수동 목차는 자동으로 제목과 페이지 번호를 다시 가져오지 않습니다.** 따라서 이미 수동 목차를 만들었다면 업데이트 버튼을 계속 누르기보다 제목 스타일을 적용하고 자동 목차로 교체하는 것이 효과적입니다.

## 0. 기존 문서 백업과 구조 확인

원본에서 바로 스타일을 전체 변경하면 제목 글꼴·크기·간격이 함께 바뀔 수 있습니다. 다른 사람이 정한 문서 양식이 있다면 특히 주의하세요.

1. **파일 → 다른 이름으로 저장** 또는 **복사본 저장**을 통해 작업 파일을 만듭니다.
2. 기존 목차와 제목의 위치를 확인하고 필요하면 PDF로 미리 저장해 비교 기준을 남깁니다.
3. **홈 → ¶ 표시/숨기기**로 빈 단락·페이지 나누기·구역 나누기 위치를 확인합니다.
4. Word의 **보기 → 탐색 창**을 열고 '제목' 목록을 확인합니다. Windows용 Word에서는 Ctrl+F로 탐색 창을 열 수도 있습니다.
5. 탐색 창에서 제목이 제대로 보이지 않는다면 문서에 제목 스타일이 없거나 구조가 일관되지 않을 가능성을 살펴봅니다.

탐색 창에 표시되지 않는다고 곧바로 본문이 삭제된 것은 아닙니다. 탐색 창은 제목 스타일을 기준으로 표시하며, Microsoft는 표·텍스트 상자·머리글·바닥글 안의 제목이 Windows용 Word 탐색 창에 나타나지 않는다고 안내합니다.

## 1. 목차에 넣을 제목에 '제목 1' 스타일 적용하기

본문의 큰 장 제목(예: '1장 서론', '2장 조사 결과')을 선택한 뒤 **홈 → 스타일 → 제목 1**을 적용합니다.

1. 목차에 나타나야 할 큰 제목 한 줄을 선택합니다.
2. **홈** 탭의 **스타일** 모음에서 **제목 1**을 누릅니다.
3. 다음 큰 제목에도 같은 스타일을 적용합니다.
4. 중간의 소제목에는 **제목 2**, 더 작은 하위 항목에는 **제목 3**을 적용합니다.
5. **보기 → 탐색 창 → 제목**을 확인하여 구조가 의도대로 들어갔는지 검토합니다.

그냥 글씨를 20포인트로 키우고 굵게 만들었다고 Word가 그 문단을 '제목 1'로 판단하는 것은 아닙니다. 반대로 제목 스타일을 적용하면 화면상 글꼴 모양이 바뀔 수 있지만, 문서 구조가 명확해지고 자동 목차·탐색 기능이 작동합니다.

### 제목 수준을 정하는 간단한 예

| 문서 구성 | 권장 스타일 |
| --- | --- |
| 1장 사업 개요 | 제목 1 |
| 1.1 사업 배경 | 제목 2 |
| 1.1.1 시장 조사 방법 | 제목 3 |
| 일반 설명 문단 | 표준 또는 본문에 해당하는 문단 스타일 |
| 표 아래 출처·그림 설명 | 제목이 아닌 별도 문단/캡션 스타일 |

이것은 예시 구조입니다. 학교·회사에서 지정한 제목 수준이 있다면 그 기준을 우선하세요. 목차에 지나치게 많은 수준을 넣으면 오히려 읽기 어려우므로 실제 문서의 깊이에 맞게 조정합니다.

## 2. 자동 목차 삽입하기

제목 스타일을 적용했다면 목차를 넣을 위치로 이동합니다. 보통 표지 뒤 또는 본문 시작 전입니다.

1. 목차가 들어갈 빈 위치에 커서를 놓습니다.
2. **참조 → 목차**를 선택합니다.
3. 목록에서 **자동 목차** 형식을 고릅니다.
4. 생성된 제목 목록과 페이지 번호를 살펴봅니다.
5. 제목이 누락됐다면 해당 문단에 제목 스타일이 적용됐는지 확인한 후 **목차 업데이트**를 실행합니다.

Word는 목차의 제목 텍스트·순서·수준과 페이지 정보를 기반으로 목차 항목을 구성합니다. 자동 목차를 만들었다고 해서 다른 모든 문서 변경이 즉시 화면에 반영되는 것은 아니므로, 중요한 수정 후 업데이트 작업을 수행해야 합니다.

**주의:** 목차의 글자를 직접 고치면 추후 전체 목차 업데이트 시 그 변경이 사라질 수 있습니다. 제목 자체를 바꾸려면 목차 글자를 편집하는 대신 **본문의 제목을 수정한 뒤 목차를 갱신**하세요.

## 3. 목차 제목은 바뀌었는데 이전 이름이 남을 때

본문에서 '조사 목적'을 '조사 목표'로 고쳤는데 목차는 이전 이름 그대로일 수 있습니다. 이때는 페이지 번호만 갱신하지 말고 **전체 목차 업데이트**를 해야 합니다.

1. 목차 안에 커서를 놓습니다.
2. **참조 → 목차 업데이트**를 선택하거나 목차를 마우스 오른쪽 단추로 클릭해 업데이트 기능을 엽니다.
3. **전체 목차 업데이트**를 선택합니다.
4. 확인 후 바뀐 제목과 페이지 번호가 반영됐는지 살펴봅니다.

Microsoft는 두 가지 업데이트 범위를 구분합니다. **페이지 번호만 업데이트**는 제목 텍스트의 변화를 무시하고 위치만 갱신합니다. **전체 목차 업데이트**는 제목 텍스트와 페이지 변경사항을 반영합니다.

제목을 고쳤다면 전체 업데이트, 내용만 추가되어 페이지가 밀렸다면 페이지 번호 업데이트가 가능하지만, 제출 직전에는 전체 업데이트가 더 적절한지 확인하는 편이 안전합니다.

## 4. 일부 제목이 목차에서 사라졌을 때

목차에 빠진 항목이 있다면 다음 순서로 확인합니다.

- **본문 제목의 스타일**: 누락된 문단을 선택했을 때 단순 굵게·글꼴 변경만 되어 있지 않은지 확인합니다.
- **제목 수준**: '제목 3'까지 목차를 보여주도록 했는데 해당 문단이 더 낮은 수준으로 구성됐는지 확인합니다.
- **목차 갱신 범위**: 페이지 번호만 업데이트했다면 새로 추가된 제목이 반영되지 않을 수 있으므로 전체 업데이트를 실행합니다.
- **텍스트 위치**: 표나 텍스트 상자 속 제목은 일반 본문 제목과 다르게 처리될 수 있으므로 문서 구조를 살핍니다.
- **사용자 지정 스타일**: 기관 양식이 자체 제목 스타일을 사용하는 경우 기본 목차가 해당 스타일을 포함하도록 설정됐는지 검토합니다.

문서의 제목을 모두 '제목 1'로 바꿔 빠진 항목을 강제로 표시하는 것은 권장하지 않습니다. 그 방법은 목차 계층을 무너뜨릴 수 있습니다. 예컨대 '연구 방법'은 제목 1이고 그 아래 '설문 설계'는 제목 2가 되어야 구조가 자연스럽습니다.

## 5. 제목 수준이나 들여쓰기가 이상할 때

목차에서 모든 제목이 같은 수준으로 나오거나, 한 제목만 지나치게 들여쓰기되는 현상이 있다면 **본문의 제목 수준과 목차 스타일을 분리**해 살펴야 합니다.

1. 본문에서 문제가 되는 제목을 클릭합니다.
2. 홈의 **스타일**에서 제목 1·제목 2·제목 3 중 실제 문서 구조에 맞는 것을 적용합니다.
3. **탐색 창**에서 상하 구조를 확인합니다.
4. 목차를 **전체 업데이트**합니다.
5. 제목의 수준은 올바른데 목차의 글꼴·들여쓰기만 이상하다면 아래 목차 스타일 사용자 지정 절차를 이용합니다.

본문 제목의 계층과 목차 자체의 서식은 별개입니다. 예컨대 본문 '제목 1'을 18포인트로 표시하면서 목차의 첫 수준은 11포인트로 표시할 수 있습니다. 이를 위해 본문 제목 스타일을 불필요하게 수정할 필요는 없습니다.

## 6. 목차의 글꼴·점선·표시 수준 조정하기

목차의 디자인을 바꾸고 싶다면 **참조 → 목차 → 사용자 지정 목차**를 확인합니다.

Microsoft 공식 안내에는 페이지 번호 표시 여부와 오른쪽 정렬, 번호 앞 탭 채움선(점선), 서식 형식, 표시할 제목 수준 등의 설정이 있습니다.

- **표시할 수준**: 제목 1~3만 보여주거나 더 깊은 수준을 포함할지 결정합니다.
- **페이지 번호**: 제출 요구사항에 따라 표시할지 결정합니다.
- **오른쪽 정렬**: 목차 페이지 번호를 오른쪽으로 맞출 수 있습니다.
- **탭 채움선**: 항목과 페이지 번호 사이의 점선 등을 설정합니다.
- **목차 스타일 수정**: 각 목차 수준(TOC 스타일)의 글꼴과 문단 서식을 변경할 수 있습니다.

목차의 실제 형식을 변경하려면 **사용자 지정 목차 → 수정**에서 해당 수준의 스타일을 편집합니다. '수정'이 회색으로 비활성화되어 있을 때는 Microsoft 도움말에 따라 서식 형식을 템플릿 기반 형식으로 바꿔야 할 수 있습니다.

목차 안에서 글자를 직접 선택해 수동으로 색이나 크기를 바꾸는 방법은 전체 업데이트 후 사라질 수 있으므로, 반복적으로 적용할 디자인이라면 **목차 스타일 자체**를 수정하는 것이 안정적입니다.

## 7. 탐색 창으로 제목 목록 검사하기

Windows용 Word의 **보기 → 탐색 창 → 제목**은 문서 구조를 점검하는 데 유용합니다.

1. 탐색 창을 열고 '제목' 탭을 선택합니다.
2. 큰 제목부터 작은 제목까지 순서가 맞는지 살펴봅니다.
3. 제목을 클릭해 본문의 실제 위치로 이동합니다.
4. 제목이 표시되지 않는 경우 제목 스타일을 확인합니다.
5. 제목이 잘못된 위치에 나타난다면 문서 본문의 제목·구역 배치부터 검토합니다.

Microsoft는 탐색 창에서 제목을 끌어서 문서 섹션을 재배치하는 기능도 안내합니다. 다만 **제목 이동은 단지 목차 순서만 바꾸는 작업이 아니라 그 아래의 본문도 이동시킬 수 있는 편집**입니다. 긴 문서에서 복사본 없이 끌어놓기를 사용하면 본문 내용이 예상과 다르게 재배치될 수 있으므로 신중해야 합니다.

표·텍스트 상자·머리글·바닥글에 들어 있는 제목이 탐색 창에서 보이지 않을 수 있으므로, 탐색 창 목록이 전체 문서 텍스트 목록을 의미하지는 않습니다.

## 8. 제목 스타일을 바꾸되 기존 문서 디자인 지키기

자동 목차를 만들려고 '제목 1'을 적용했더니 글씨가 파랗게 변하거나 크기가 커졌다면, 문서의 제목 스타일 디자인을 수정할 수 있습니다.

1. 먼저 문서의 제목 하나에 **제목 1** 스타일을 적용합니다.
2. 학교·회사 양식에 맞춰 글꼴과 크기, 색, 간격을 조정합니다.
3. 홈의 스타일 갤러리에서 **제목 1**을 마우스 오른쪽 단추로 선택합니다.
4. 필요에 따라 **선택 영역에 맞게 제목 업데이트** 또는 **수정** 기능을 사용합니다.
5. 문서 내 다른 제목 1 문단에도 변경이 적용됐는지 확인합니다.

Microsoft는 스타일 갤러리에서 스타일을 수정하거나 기존 선택 서식에 맞게 업데이트할 수 있다고 안내합니다. 이런 변경은 **같은 스타일이 적용된 여러 제목에 영향을 줄 수 있으므로** 전체 문서의 레이아웃을 확인해야 합니다.

기관에서 지정한 템플릿을 쓰고 있다면 자체 제목 스타일이 정의돼 있을 수 있습니다. 해당 스타일을 임의로 덮어쓰기 전에 제출 규칙과 현재 템플릿의 스타일 구성을 확인하세요.

## 9. 웹용 Word·Mac용 Word에서 주의할 점

Microsoft 공식 안내는 Windows, macOS, 웹용 Word에서 자동 목차의 기본 원리를 설명합니다. 웹용 Word에서도 제목 스타일을 적용해 목차를 추가·갱신할 수 있지만 메뉴 구성과 고급 사용자 지정 범위는 데스크톱 앱과 다를 수 있습니다.

- **Windows**: 참조 탭의 목차·업데이트, 홈의 스타일, 보기의 탐색 창을 확인합니다.
- **Mac**: 목차 생성·업데이트와 제목 스타일의 기본 원리는 같습니다. 다만 리본 메뉴 구성·단축키가 다르므로 실제 표시 항목을 기준으로 진행합니다.
- **웹용 Word**: 자동 목차와 제목 스타일을 사용할 수 있습니다. 고급 목차 서식이나 기존 템플릿의 복잡한 필드 제어가 어려우면 데스크톱 앱에서 확인합니다.

기관에서 만든 문서가 **편집 제한** 상태라면 제목 스타일을 바꾸거나 필드를 업데이트할 권한이 없을 수 있습니다. 보호를 무작정 해제하려 하지 말고 문서 소유자나 IT 담당자에게 요청하세요.

## 10. 목차가 틀어질 때 상황별 해결표

| 문제 | 우선 확인 | 하지 말아야 할 일 |
| --- | --- | --- |
| 제목이 아예 안 나옴 | 제목 스타일 적용 여부 | 목차에 직접 제목 입력 |
| 새 제목이 누락됨 | 전체 목차 업데이트 | 페이지 번호만 갱신하고 종료 |
| 제목이 이전 이름으로 남음 | 본문 제목 수정 후 전체 갱신 | 목차 항목만 수동 수정 |
| 페이지 번호가 전부 어긋남 | 문서 배치 확정 후 목차 업데이트 | 번호를 하나씩 손으로 고치기 |
| 목차 들여쓰기가 이상함 | 본문 제목 수준·목차 스타일 | 모든 제목을 제목 1로 통일 |
| 점선·글꼴이 갱신 후 원래대로 돌아옴 | 사용자 지정 목차·목차 스타일 | 목차 텍스트에만 직접 서식 |
| 탐색 창에서 제목이 안 보임 | 제목 스타일·문단 위치 | 표나 텍스트 상자를 무작정 삭제 |
| 목차가 업데이트되지 않음 | 자동/수동 목차 구분 | 수동 목차에서 자동 업데이트 반복 |

## 인쇄·PDF 저장 전 검증 체크리스트

- [ ] 목차에 필요한 모든 장과 절 제목이 포함됐다.
- [ ] 제목 1·제목 2·제목 3의 계층이 실제 내용과 일치한다.
- [ ] 불필요한 본문 문단이 목차 항목으로 들어가지 않았다.
- [ ] 본문에서 수정한 제목이 목차에 반영됐다.
- [ ] 문서의 최종 편집이 끝난 다음 **전체 목차 업데이트**를 실행했다.
- [ ] 탐색 창에서 제목 순서를 확인했다.
- [ ] 페이지 번호와 점선, 들여쓰기가 제출 양식과 일치한다.
- [ ] 제목 스타일 변경으로 본문 간격·페이지 배치가 의도치 않게 바뀌지 않았다.
- [ ] **파일 → 인쇄** 미리보기에서 목차가 잘리거나 겹치지 않는다.
- [ ] PDF로 저장한 뒤 목차와 실제 본문 페이지 번호를 비교했다.
- [ ] 문제가 생기면 되돌릴 수 있도록 원본 파일과 수정본이 구분돼 있다.

문서에 표지와 목차가 포함되어 있을 때 Word 문서 내부의 인쇄된 페이지 번호와 PDF 뷰어의 전체 페이지 순서는 다를 수 있습니다. **목차의 번호가 맞는지**는 Word에서 지정한 본문 페이지 번호 체계와 실제 본문을 기준으로 검토하세요. 페이지 번호를 표지 다음부터 시작하는 방법은 별도의 GuideHollow Word 가이드에서 다룹니다.

## 자주 묻는 질문

### Q. 목차가 자동으로 바뀌게 하려면 어떤 기능을 써야 하나요?

**제목 스타일**을 적용한 뒤 **참조 → 목차 → 자동 목차**를 삽입합니다. 문서를 수정한 다음에는 목차 업데이트로 변경 사항을 반영합니다. 제목 스타일 없이 글자 크기만 바꾼 경우 자동 목차에서 빠질 수 있습니다.

### Q. 제목은 바뀌었는데 목차에서 이름이 안 바뀌어요.

**페이지 번호만 업데이트**가 아니라 **전체 목차 업데이트**를 선택하세요. Microsoft는 전체 업데이트가 제목 텍스트와 페이지 변경을 반영한다고 설명합니다.

### Q. 목차에 제목 3이 안 나와요.

본문에 제목 3 스타일이 적용됐는지 확인하고, 사용자 지정 목차에서 **표시할 수준**이 충분한지 살펴봅니다. 문서의 제목 구조를 유지하면서 목차에 보여줄 깊이를 조정하는 것이 좋습니다.

### Q. 제목 스타일을 적용하면 기존 글꼴 디자인이 망가지지 않나요?

스타일 적용으로 글꼴·크기·간격이 달라질 수 있지만 해당 스타일을 문서 양식에 맞게 수정할 수 있습니다. 하나의 스타일을 바꾸면 같은 스타일의 다른 제목에도 적용될 수 있으니 원본을 먼저 보관하고 전체 문서를 확인하세요.

### Q. 수동으로 만든 목차도 업데이트 단추로 고칠 수 있나요?

일반적으로 안 됩니다. Microsoft는 수동 목차는 제목을 원본으로 하는 자동 목차가 아니어서 변경 내용을 직접 입력해야 한다고 안내합니다. 자동 갱신이 필요하면 제목 스타일을 적용하고 자동 목차로 만드는 편이 좋습니다.

### Q. 탐색 창에서 제목을 끌어 놓으면 목차 순서만 바뀌나요?

아닙니다. 해당 제목 아래의 문서 내용까지 이동할 수 있습니다. 긴 보고서에서는 원본 복사본을 확보하고 이동 뒤 내용의 순서·누락·페이지 배치까지 확인하세요.
